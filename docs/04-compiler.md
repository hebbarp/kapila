# Kapila Compiler (kapilac)

## Overview

`kapilac` is the Kapila compiler that transforms `.kpl` source files into native executables via C code generation.

## Usage

```bash
# Show help
kapilac --help

# Show version and compiler info
kapilac -v

# Output generated C code to stdout
kapilac program.kpl

# Output to file
kapilac program.kpl -o output.c

# Compile and run immediately
kapilac program.kpl -r

# Compile, run, and keep temporary files
kapilac program.kpl -r -k

# Compile from string
kapilac -c '೫ ೩ ಕೂಡು ಮುದ್ರಿಸು.'
```

## Command-Line Options

| Option | Description |
|--------|-------------|
| `input.kpl` | Input Kapila source file |
| `-o FILE` | Output C file path |
| `-r, --run` | Compile and run immediately |
| `-c CODE` | Compile code from command line |
| `-k, --keep` | Keep generated temporary files |
| `-v, --version` | Show version and compiler info |

## Compilation Pipeline

```
┌──────────────┐
│ kapilac.py   │
└──────┬───────┘
       │
       ▼
┌──────────────┐     ┌──────────────┐
│ Parse        │ ──▶ │ Generate C   │
│ (parser.py)  │     │ (c_gen.py)   │
└──────────────┘     └──────┬───────┘
                            │
       ┌────────────────────┘
       ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ program.c    │     │ kapila.c     │     │ kapila.h     │
│ (generated)  │     │ (runtime)    │     │ (runtime)    │
└──────┬───────┘     └──────┬───────┘     └──────────────┘
       │                    │
       └────────┬───────────┘
                ▼
       ┌──────────────┐
       │ C Compiler   │
       │ (tcc/gcc)    │
       └──────┬───────┘
              │
              ▼
       ┌──────────────┐
       │ program.exe  │
       └──────────────┘
```

## Bundled TinyCC

The standalone distribution includes TinyCC (Tiny C Compiler), a small and fast C compiler:

- **Size**: ~1MB (vs GCC's 500MB+)
- **Speed**: Very fast compilation
- **Self-contained**: No external dependencies

The compiler automatically detects TinyCC in these locations:
1. `tcc/` directory (bundled with distribution)
2. `tools/tcc/` (development)
3. System PATH

If TinyCC is not found, it falls back to GCC.

## Examples

### Basic Compilation

```bash
# Create a simple program
echo '೫ ೩ ಕೂಡು ಮುದ್ರಿಸು.' > test.kpl

# Compile and run
kapilac test.kpl -r
# Output: 8
```

### View Generated C Code

```bash
kapilac test.kpl
```

Output:
```c
/* Generated by Kapila Compiler */
#include "kapila.h"

int main() {
    kapila_init();

    push_int(5);
    push_int(3);
    add_op();
    println_op();

    kapila_cleanup();
    return 0;
}
```

### Manual Compilation

```bash
# Generate C code
kapilac program.kpl -o program.c

# Compile manually with TinyCC
tcc -o program program.c kapila.c

# Or with GCC
gcc -O2 -o program program.c kapila.c
```

## Error Handling

The compiler provides error messages for:

- Syntax errors (from parser)
- Unknown words
- C compilation errors (from tcc/gcc)

```bash
kapilac bad.kpl -r
# Compilation error: unknown type name 'xyz'
```

## Building the Compiler

The compiler is a Python script that can be:

1. **Run directly**: `python kapilac.py`
2. **Packaged as .exe**: Using PyInstaller (see `build_dist.py`)

## Distribution

The standalone distribution (`kapila-windows-x64.zip`) includes:

```
kapila/
├── kapilac.exe     # Compiler executable
├── kapila.exe      # REPL/Interpreter
├── runtime/        # C runtime library
│   ├── kapila.h
│   └── kapila.c
├── tcc/            # Bundled TinyCC compiler
├── examples/       # Sample programs
└── README.md
```
