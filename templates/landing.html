Kapila is a programming language you write in Kannada. Values come first and the verb comes last, just as in a Kannada sentence. Live news, weather and Wikipedia are one word away.

What's inside

Live data in the language

ಸುದ್ದಿ, ಹವಾಮಾನ and ವಿಕಿ are ordinary words that return records. Filter them, sort them and combine them into something new.

A neural network built from scratch

PicoNN is Kapila's own small neural network library, with no outside machine-learning framework underneath.

Text handled by akshara

Pampa works on Indic text the way readers see it, one akshara at a time rather than one code point at a time.

Your language next

A language-pack protocol is in the works, so anyone can fork Kapila into their own language. Follow along or help build it on GitHub.
